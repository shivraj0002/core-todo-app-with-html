# Core Todo App With Html

A core todo application built with plain HTML, CSS, and JavaScript, utilizing a state management approach with an array of objects. This project is designed for brushing up knowledge on fundamental web development concepts, including DOM manipulation, event handling, and inline styling.

## Features
- Add new todos with a simple input field
- Remove todos with a dedicated button
- State management using an array of objects for todos
- Responsive design with clean, generic color styling
- Inline CSS for easy maintenance

## Preview
Check out a preview of the app here: [https://shivraj0002.github.io/core-todo-app-with-html/](https://shivraj0002.github.io/core-todo-app-with-html/)

## Purpose
This project serves as a practice tool to reinforce understanding of:
- Plain JavaScript for state management
- DOM manipulation without frameworks
- Basic CSS styling techniques
- Event-driven programming

## Getting Started
1. Clone the repository
2. Open `index.html` in a web browser
3. Start adding and removing todos!
